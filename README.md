<h1 align="center">语滴 Lingo Sip · 碎片英语</h1>

<p align="center">在浏览网页的空档，安静地学一个词。</p>
<p align="center">Chrome / Edge · Manifest V3 · 零依赖 · 数据保存在本地</p>

**语滴是一款把英语复习融入日常浏览的浏览器扩展。** 它会在切换标签、页面加载完成或短暂停顿时尝试递出一张单词卡，并通过冷却时间、频率上限、安静时段与页面状态减少打扰。你也可以主动打开学习窗口，按自己的节奏连续练习。

不需要注册或运行服务器。下载源码后即可加载为浏览器扩展；词库、学习进度、设置和备份都由你自己掌握。

## 功能一览

| 功能 | 可以做什么 |
| --- | --- |
| 低打扰单词卡 | 在普通网页上展示词义、音标、例句与学习动作；正在输入、选中文字、播放未静音音视频或全屏时避免自动打扰 |
| 间隔重复复习 | 使用盒子模型安排复习；自动提醒优先到期复习及额度内新词，主动学习支持提前练习 |
| 多种学习入口 | 工具栏面板、右键菜单、快捷键、新标签页与独立连学窗口 |
| 本机发音 | 使用浏览器与系统的本地英语声音；支持选声音、试听和调语速，失败时提供反馈 |
| 内置词库 | 128 个高频单词与 36 个常用短语，覆盖办公、会议、邮件、技术、日常、旅行与学术场景 |
| 自定义生词本 | 导入 CSV、TSV 或 JSON，先预览再确认；支持搜索、筛选、分页、编辑及删除撤销 |
| 今日足迹 | 区分看过卡片与主动作答，可选择每日目标口径，查看学习状态和连续记录 |
| 数据备份 | 完整备份导出、合并或覆盖导入；每天保留快照，最多保留最近 7 份 |
| 桌面提醒 | 按需开启系统通知，并控制通知频率与声音 |
| 深浅主题 | 界面跟随系统主题，支持键盘操作及清晰的焦点反馈 |

产品示意可下载并打开 [docs/index.html](docs/index.html)，单词卡样式可在安装扩展后打开 [tools/preview.html](tools/preview.html) 查看。示意页面用于介绍设计，实际功能以加载后的扩展为准。

## 安装：下载后直接加载

1. 在 GitHub 仓库页面选择 **Code → Download ZIP** 并解压，或使用 Git 克隆仓库。
2. 把项目放到准备长期保留的位置。需要选择的是**包含 `manifest.json` 的目录**。
3. 在浏览器中打开扩展管理页面：Chrome 使用 `chrome://extensions`；Edge 使用 `edge://extensions`。
4. 打开**开发者模式 / 开发人员模式**，选择**加载已解压的扩展程序 / 加载解压缩的扩展**，再选择项目目录。
5. 按首次引导选择词库场景、提醒节奏和目标，然后试学一张。确认引导前保持手动学习，通知默认关闭。
6. 刷新已打开的普通网页，使内容脚本生效。

**安装和使用不需要 Node.js，也不需要执行 `npm install`。** 扩展清单要求 Chromium 110 或更新版本；当前针对桌面 Chrome / Edge 构建。

加载后的目录位置会影响未打包扩展的身份。已有学习数据时，移动、重命名目录或移除扩展前，请先在设置页导出完整备份。更新源码后，在扩展管理页点击刷新；内容脚本改动还需要刷新网页。

## 快速上手

| 你想做的事 | 操作 |
| --- | --- |
| 主动学习 | 点击扩展图标 → **立即学一张**，或打开连学窗口 |
| 在当前网页学一张 | 使用右键菜单，或按 `Alt+Shift+E` |
| 记住当前词 | 点击 **记得了**，或按 `1`；长期掌握状态由复习等级决定 |
| 之后再复习 | 点击 **稍后复习**，或按 `2` |
| 听发音 | 点击发音按钮，或按 `空格` |
| 多看一会儿 | 鼠标停在卡片上，自动暂停倒计时；连学卡片可用“全文”阅读长内容 |
| 关闭当前卡片 | 按 `Esc` |
| 暂停自动提醒 | 工具栏面板选择 **15 分钟 / 1 小时 / 4 小时 / 今天** |
| 避开某个网站 | 在设置页的免打扰名单中添加域名或 URL 通配规则 |
| 调整学习内容 | 在设置页选择内置分类，或导入自己的生词本 |

自动网页卡片默认停留 25 秒。没有作答时会淡出，记为展示并安排稍后再次出现，不计为答错。新标签页上的卡片不会自动淡出。开启“回忆模式”后，可以先回忆，再查看释义。

新标签页顶部保留搜索与网址输入，下方展示学习卡片和今日进度。新标签页覆盖由扩展清单声明；可在浏览器支持的扩展详情设置中关闭这一入口。Chrome 与 Edge 的管理界面选项可能不同。

## 提醒怎样控制打扰

自动提醒采用“时机申请 → 频率与状态检查 → 当前页面确认”的流程。后台统一决定是否展示，页面侧可以因输入、选区、媒体播放或全屏状态拒绝自动展示。

标准默认值如下，首次引导选择不同节奏后可能调整这些参数：

| 设置 | 默认值 |
| --- | --- |
| 全局冷却 | 两次展示至少间隔 4 分钟 |
| 每小时上限 | 5 张 |
| 每日上限 | 30 张 |
| 同标签页冷却 | 5 分钟 |
| 页面停顿判断 | 30 秒没有鼠标、键盘或滚动动作 |
| 定时兜底 | 45 分钟 |
| 自动发音 | 关闭 |
| 离开电脑后返回提醒 | 关闭 |

暂停、安静时段、免打扰名单和页面状态会共同影响展示。设置页的诊断区域会记录最近一次未展示的原因，方便排查冷却、配额或页面条件。

## 自定义词库

设置页支持导入 CSV、TSV 和 JSON。导入先显示新增、更新与身份冲突，确认后才写入；同词更新会保留学习身份，冲突行会明确跳过。

最简 CSV：

```csv
term,meaning
resilient,有韧性的；能迅速恢复的
schedule,日程表；安排
```

也可以使用完整字段：

```csv
term,phonetic,pos,meaning,example,exampleZh,tags,level
resilient,/rɪˈzɪliənt/,adj.,有韧性的,She stayed resilient after the setback.,遭遇挫折后她依然坚韧。,office|core,2
```

首行表头支持中文或英文，也支持直接粘贴 JSON。词条管理提供搜索、学习状态筛选、每页 20 条分页及释义、音标、例句、类型和标签编辑。删除自定义词或清空后，10 秒内可以撤销；学习记录仍保留。

开发者可以修改 `src/data/words.js` 的内置词表。**已有词条的 `id` 必须保持稳定**，因为进度按词条身份关联。词库也可以导出，用于迁移或在其他工具中整理。

## 数据与隐私

- 学习进度、词库、设置和统计保存在 `chrome.storage.local`，没有账号体系、后台服务或远程同步。
- 学习模块不调用在线词典、在线翻译或在线发音服务；发音仅选择本地声音。
- 没有分析统计或遥测代码。新标签页搜索和网址输入会按你的操作跳转到外部网站，搜索默认使用 Bing。
- 开发自动重载默认关闭。启用后只轮询本机 `localhost` 开发服务。
- 导出的备份包含你的词条和学习记录，属于个人数据。请自行保管，勿上传到公开仓库。

备份入口位于设置页的“数据与备份”。导入分为两种模式，**预览和确认之前不会改动学习数据**：

| 模式 | 行为 | 适用情况 |
| --- | --- | --- |
| 合并，默认 | 补充缺失内容，合并记录并保护已有进度 | 合并旧备份或补回部分词条 |
| 覆盖 | 用备份替换当前状态 | 已核对内容后的完整迁移 |

跨天时会自动保留一份快照，最多保留最近 7 份；也可以手动保存。恢复快照前会先保存当前状态，方便需要时再恢复。

扩展声明的权限及用途：

| 权限或声明 | 用途 |
| --- | --- |
| `storage` | 本地学习数据、设置与备份 |
| `alarms` | 周期调度与跨天处理 |
| `idle` | 判断设备空闲或返回状态 |
| `tabs` | 找到当前活动标签页，控制展示位置 |
| `tts` | 使用本机语音朗读 |
| `notifications` | 用户启用后展示系统提醒 |
| `contextMenus` | 提供网页右键学习入口 |
| HTTP / HTTPS 内容脚本 | 在普通网页检测交互状态并展示学习卡片 |
| `chrome_url_overrides.newtab` | 提供新标签页学习入口 |

内容脚本覆盖普通 HTTP / HTTPS 网页。浏览器内部页面、扩展管理页以及禁止注入的页面不能展示网页卡片。

## 开发与验证

原生 JavaScript、HTML 与 CSS 实现，Manifest V3 Service Worker 负责调度，Shadow DOM 隔离网页卡片样式。没有 npm 依赖和构建步骤；开发验证需要 Node.js，推荐使用 Node.js 24。

修改后至少运行：

```bash
node tools/validate.js
node tools/selftest.js
```

前者检查清单、模块语法、词库、HTML 资源、元素引用与版本一致性；后者运行 **150 项核心逻辑断言**。体检用模拟浏览器 API 加载模块，内容脚本可能输出一条预期的加载提示，以最终检查结果和退出码为准。

更多已有工具：

| 命令 | 用途 |
| --- | --- |
| `npm test` | 核心与独立回归套件；各套件使用隔离进程和模拟存储 |
| `npm run test:browser` | 使用临时浏览器配置检查主要页面和交互 |
| `npm run test:study` | 检查连学窗口的尺寸、主题和缩放布局 |
| `npm run test:popup` | 检查浏览器实际打开的工具栏面板 |
| `npm run dev` | 本机开发重载服务，需在设置页开启开发重载 |
| `npm run icons` | 重新生成图标资源 |

浏览器验证脚本默认寻找 Windows Edge，可用 `--browser=<浏览器路径>` 指定可执行文件，并用 `--output=<目录>` 指定报告位置。它们创建临时测试配置，使用合成进度，不以日常浏览器配置进行验收。自动化通过不等于所有浏览器版本、系统通知和本机语音都已验证，仍需在目标环境实际检查。

开发重载不能自动应用 `manifest.json` 的变化；内容脚本的变化也需要重新加载相关网页。

可选打包：

```bash
node tools/pack.mjs
node tools/verify-crx.mjs
```

打包器使用 Node.js 内置模块生成 ZIP 和 CRX3，首次运行在 `.keys/` 下创建本地签名密钥，产物位于 `dist/`。**密钥不要提交到公开仓库，请在本地安全保管。** 加载已解压扩展不会自动拉取本仓库更新。

## 可选：从旧存储副本导出备份

正常迁移优先使用设置页导出。恢复工具只在你明确指定目录或扩展 ID 后读取 LevelDB 的 `.log` 文件，不扫描或自动选择浏览器存储。

请先关闭浏览器，或把旧存储目录复制到其他位置后再读取。建议将备份输出到仓库之外：

```bash
node tools/recover-from-edge.js "<存储目录副本>" "<仓库外的备份文件.json>"
node tools/recover-from-edge.js --help
```

也可以指定浏览器配置与扩展 ID：

```bash
node tools/recover-from-edge.js --browser=edge --profile=Default --extension-id=<旧扩展ID> --output=<仓库外的备份文件.json>
```

Windows 默认用户数据目录从 `%LOCALAPPDATA%` 推导，Profile 默认为通用的 `Default`。可在 `edge://version` 或 `chrome://version` 查看自己的配置路径，再通过 `--profile` 或 `--user-data-dir` 明确指定。

支持的环境变量为 `LINGO_SIP_BROWSER`、`LINGO_SIP_PROFILE`、`LINGO_SIP_USER_DATA_DIR`、`LINGO_SIP_EXTENSION_ID`、`LINGO_SIP_BUCKET` 和 `LINGO_SIP_OUTPUT`，命令行参数优先。未提供存储目录或扩展 ID 时，仅显示说明并退出。

该工具不解析全部 LevelDB 格式；日志已经压缩、删除或损坏时可能无法恢复。它不会修改原存储目录。导出的 JSON 应通过设置页预览，再按需要选择合并导入。
