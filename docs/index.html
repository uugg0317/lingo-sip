它不会占用你任何一段时间

这三个原则决定了它和所有背单词 App 的区别。

1

只用你本来就会浪费掉的时间

切完标签、页面刚加载完、在某页上停手 30 秒——只有这些时刻才尝试出现。没有课程表，没有每日必修，学不完也没有任何惩罚。

2

你在忙的时候，它一句话都不说

正在输入、选中了文字、在看视频、全屏、不在当前标签页——任何一条成立就绝不打扰。决策权只集中在一个地方，不会十个标签页各弹各的。

3

没作答不算错

卡片 25 秒后自己淡出，只记一次"见过"，20 分钟后再来。永远攒不出还不完的复习债。

同一个词，多久再见一次

每答对一次就退到更远的盒子，间隔逐档拉长。这是它能在碎片时间里生效的原因—— 它不靠你每天来，靠的是让每次回忆都发生在快忘掉的时候。

六项权限，各有用途

它只要这六项，每一项都能说清为什么。

storage
存学习进度、设置与统计
alarms
每分钟一次的定时兜底与跨天归零
idle
判断你是否离开电脑，离开时绝不打扰
tabs
知道当前在哪个标签页，只在你看的那页出现
tts
离线朗读，不依赖任何在线发音服务
notifications
浏览器不在前台时，用系统通知把单词送到桌面
每天自动备份
跨天时自动留一份快照，保留最近 7 份。恢复前会先给"现在"留一份，所以恢复错了也能退回来。
导入是合并，不是覆盖
导入备份前先算差异、给出预览，确认之前不写任何数据。只补缺的词，不回退已掌握的进度。
生词本可以带走
支持 CSV / TSV / JSON 导入导出，能搬到 Excel、Anki 或别的工具里，随时一键暂停。

现在装上

零依赖、零构建、纯本地。约 1 分钟。

加载已解压的扩展程序
  1. 地址栏打开 edge://extensions，Chrome 用 chrome://extensions
  2. 打开「开发人员模式」
  3. 点「加载解压缩的扩展」，选择含 manifest.json 的那一层文件夹

装好后刷新一下已开着的标签页——浏览器只会把内容脚本注入到之后新加载的页面里。
